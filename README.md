# Composite Prefetching in ChampSim (C1 + T2 Implementation)

## Overview

This repository contains an implementation of two hardware prefetcher components in **ChampSim (2023 fork)** based on the methodology proposed in:

Kondguli, S., & Huang, M.  
"Division of Labor: A More Effective Approach to Prefetching", ISCA 2018.

The design philosophy follows the **division-of-labor approach**, where multiple specialized prefetcher components operate with high accuracy instead of using a single monolithic prefetcher with broad but inaccurate scope.

This implementation includes:

- **T2 Prefetcher** — Canonical Stride Stream Prefetcher  
- **C1 Prefetcher** — Region-Based High Spatial Locality Prefetcher  

---

# Scientific Background

The core idea of the referenced work is that prefetchers must balance:

- **Prefetching Scope** — How much of the miss stream is targeted  
- **Effective Accuracy** — Misses avoided per prefetch issued  

Traditional monolithic prefetchers increase scope but suffer from reduced effective accuracy due to pollution.

The composite approach instead:

- Uses specialized components
- Maintains high effective accuracy
- Coordinates components to reduce interference

# T2 Prefetcher

## Target Pattern

T2 detects:

- Canonical strided memory streams
- Generated by a single static instruction
- Typically inside an inner loop

## Microarchitectural Structures

### Stride Identifier Table (SIT)

Each entry tracks:

- PC (static instruction)
- Last accessed address
- Stride (delta)
- Confidence counter

## Detection Policy

- 16 consecutive identical deltas → classify as STRIDED
- 4 consecutive mismatches → classify as NON-STRIDED

## Prefetch Generation

Once classified as strided:
next_address = current_address + delta


Prefetch degree and distance are configurable.

# C1 Prefetcher

## Target Pattern

C1 targets high spatial locality regions.

Instead of predicting stride, it predicts dense regions of memory and prefetches entire regions.

## Structures Implemented

### Region Monitor (RM)

Tracks:

- Region tag
- 16-bit cache-line bitmap
- PC association bit vector

### Instruction Monitor (IM)

Tracks:

- TotalRegions counter
- DenseRegions counter

## Training Rule

When:
DenseRegions / TotalRegions > 0.75
